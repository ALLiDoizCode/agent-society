## DEEP STORY ANALYSIS — Patterns Across Epic 44

### Strengths

**1. Cross-repo doc discipline established.**
Body-identical mirror with `tail -n +4` drift detection (3-line `<!-- ... -->` comment header on the mirror; producer-side file is canonical and headerless). One-line `diff` invocation detects drift. Pattern is portable to any future cross-repo doc.

**2. Section-order discipline in long-lived docs.**
44.4 *inserted* `## API stability` between existing `## Stability guarantees` and `## Supply-chain signing` — no rewrites. Future maintainers can append without rebuilding. The doc grew 2 sections and stayed coherent.

**3. Contract canary held the line.**
`packages/sdk/tests/integration/connector-contract.test.ts` did not regress across 8 connector PRs and 4 connector version bumps. The canary's design is paying for itself.

**4. Drive-by fix discipline.**
Story 44.3 left `pull/<num>` placeholders on lines 39 + 153 of `CONNECTOR_RELEASE_CONTRACT.md`. Story 44.4 bundled the substitution as Task 2.4, saving a third connector PR. Aggregating cleanup into the next adjacent PR is correct when the cleanup is small and unambiguous.

**5. Conventional-commit prefix correctness.**
`docs(release): ...` on the 44.4 connector PR mapped to no semantic-release version bump — exactly right for a *forward-applying* contract. The contract takes effect on the next organic feat/fix release, not on the doc PR itself.

**6. Cosign keyless OIDC at v3.6.0.**
`cosign verify` is now possible against connector images without managing keypairs. Table-stakes for serious DePIN operators; shipped before pilot recruitment fires.

### Challenges

**1. Cross-repo PR-timing failure (most consequential).**
Connector#67 merged before round-2 review patches (P3–P7, Q1) could be pushed. Six fixes verified body-clean during local review never made it upstream. Connector cut v3.6.1 from #67's content without those polish fixes. Now requires a follow-up cycle (one connector PR + one town mirror PR) to resolve.

Root cause: no pre-merge checklist gate that says "all round-2 commits pushed before requesting re-review." The two-phase review pattern (round-1, then round-2 after patches) is correct but ungated.

**2. Sprint-status YAML scope-creep via merge-conflict resolution.**
When `chore/44-4-close-out` rebased onto main and hit a conflict on `sprint-status.yaml`, the resolution shortcut ("take stash version") carried in ~10 unrelated Epic 21 status changes (`21-8-5` through `21-15`, three inserted keys, 17-line re-entry-resequence comment block). Caught in review (Finding D1) and reverted, but should never have entered the diff.

Root cause: `sprint-status.yaml` is a flat shared file that any branch touches; conflict resolution shortcuts are wrong every time. The right move is `git checkout --conflict=diff3` and surgical hunk selection.

**3. Incomplete execution of documented patterns.**
Story 44.3 documented the "open with placeholder, capture PR number, push fix" pattern but didn't fully execute it — `pull/<num>` placeholders shipped to `origin/main` on lines 39 + 153. Pattern is sound; the *execution checklist* for it is missing.

**4. Docs-only stories accumulate small content debt fast.**
44.4 had 8 ACs all pass and 13 review findings + 6 deferred polish items still surfaced. Adversarial review caught everything important. Without adversarial review, the polish items would have shipped and ossified.

**5. Retrospective cadence lapsed.**
Last retro was Epic 11 (2026-04-09). Epics 12–43 went un-retro'd. Lessons from connector-pinning, x402, ATOR, dashboard, and migration work were not captured.

## SIGNIFICANT DISCOVERY — Forward-Applying Contract Language

The forward-applying language in `CONNECTOR_RELEASE_CONTRACT.md` — specifically the `### Townhouse pin discipline` paragraph — references `image-manifest.json` in present tense. The file does not yet exist; Story 45.2 will produce it. This is *deliberate forward-applying language* per the doc's design intent, but Story 45.2's reviewer should be aware that the contract's prose presupposes the artifact 45.2 ships.

**Impact:** Story 45.2's PR body should explicitly cite the `### Townhouse pin discipline` paragraph and confirm the artifact it produces matches the prose. If the artifact diverges (different filename, location, or shape), the contract needs an amendment in lock-step.

**Recommended action:** Add a one-line cross-reference to `CONNECTOR_RELEASE_CONTRACT.md` in Story 45.2's spec when it is created. Not blocking — just flagged.

**Epic update required:** No. The Epic 45 plan is structurally sound. The contract-artifact alignment is a story-level reviewer-attention item.

## KEY TAKEAWAYS

1. **Cross-repo doc discipline works** — body-identical mirror with header-stripped diff is a portable pattern that scales beyond CONNECTOR_RELEASE_CONTRACT.md.
2. **Two-phase review needs a pre-merge gate** — connector#67 merging before round-2 patches landed is the single most consequential failure of this epic.
3. **YAML merge conflicts on shared state files require surgical resolution** — `take-stash` is the wrong default and caused real damage on 44.4 (caught in review).
4. **Docs-only stories accumulate small content debt fast** — adversarial review (Blind Hunter + Edge Case Hunter + Acceptance Auditor) is the right antidote.
5. **Retrospective cadence has lapsed** — last retro was Epic 11; Epics 12–43 went un-retro'd. Capturing lessons within the sprint matters.
